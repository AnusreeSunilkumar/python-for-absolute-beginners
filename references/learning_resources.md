# Learning Resources

This page contains additional resources for learners who would like more explanations, examples, exercises, or video lessons.

You do not need to complete every resource listed here. Choose one or two resources that match your preferred learning style and use them alongside this tutorial.

Some resources are completely free, while others may require payment for full access, graded assignments, or certificates. Prices and access conditions may change over time.

## Official Python Resources

### Python Documentation 

- [Python Documentation](https://docs.python.org/3/) 
- [The Python Tutorial](https://docs.python.org/3/tutorial/) 
- [Python Standard Library](https://docs.python.org/3/library/) 
- [Python Download Page](https://www.python.org/downloads/)

The official documentation is the most reliable source for checking Python syntax, built-in functions, standard-library modules, and current language behavior. 

The official Python tutorial assumes some general programming knowledge, so complete beginners may find it easier to use it as a reference rather than as their only learning resource.

## Recommended Books

### Python Crash Course

**Author:** Eric Matthes

*Python Crash Course* introduces Python fundamentals through explanations, exercises, and practical projects.

It is a good choice for learners who prefer a structured, project-based book.

- [Official book page](https://nostarch.com/python-crash-course-3rd-edition)

### Think Python

**Author:** Allen B. Downey

*Think Python* focuses on programming concepts and problem-solving. It is suitable for people who are learning programming for the first time.

The third edition is available online and uses Jupyter notebooks.

- [Read Think Python online](https://allendowney.github.io/ThinkPython/) 
- [Green Tea Press](https://greenteapress.com/wp/think-python-3rd-edition/)

### Head First Python

**Author:** Paul Barry

*Head First Python* uses illustrations, examples, and a visually oriented teaching style.

It may be useful for learners who prefer explanations that are less formal and more visual.

- [Official publisher page](https://www.oreilly.com/library/view/head-first-python/9781492051282/)

## Free Online Courses

### CS50's Introduction to Programming with Python

**Provider:** Harvard University

This course introduces programming with Python and covers functions, variables, conditions, loops, exceptions, libraries, testing, file input and output, and object-oriented programming. 

It is suitable for learners with or without previous programming experience. 

- [CS50 Python course](https://cs50.harvard.edu/python/) 
- [CS50 Python on edX](https://www.edx.org/learn/python/harvard-university-cs50-s-introduction-to-programming-with-python) 

The course materials can be accessed for free. Certificate conditions may differ depending on the platform.

### Python for Everybody

**Instructor:** Charles Severance 
**Provider:** University of Michigan

Python for Everybody is designed for learners without a programming background. Its website provides lessons, videos, a book, and assignments. 

- [Python for Everybody website](https://www.py4e.com/) 
- [Python for Everybody lessons](https://www.py4e.com/lessons) 
- [Programming for Everybody on Coursera](https://www.coursera.org/learn/python) 

Coursera may allow learners to access some course materials without purchasing a certificate. Available access options can change.

### freeCodeCamp 

freeCodeCamp provides free programming tutorials and long-form video courses.

## Getting Help

When you encounter a problem:

1. Read the complete error message. 
2. Start reading the traceback from the final line. 
3. Check variable names, spelling, indentation, and brackets. 
4. Review the relevant lesson. 
5. Reduce the program to a smaller example. 
6. Search the official Python documentation. 
7. Ask a clear question and include the relevant code and error message.
